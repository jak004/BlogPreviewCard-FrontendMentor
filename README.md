# Blog Preview Card

A responsive blog preview card built from scratch using HTML and CSS.

This project was created as a frontend practice project based on a provided design. The goal was to recreate the design as closely as possible while practicing responsive layouts, CSS styling, and semantic HTML.

## 🚀 Features

* Responsive design for desktop and mobile screens
* Semantic HTML structure
* Custom Figtree font
* Hover and keyboard focus states
* Responsive card layout
* CSS Grid and Flexbox
* Accessible image alt text

## 🛠️ Built With

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Responsive Design

## 📂 Project Structure

```text
blog-preview-card/
├── index.html
├── style.css
└── assets/
    ├── fonts/
    └── images/
```

## 💻 Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/blog-preview-card.git
```

2. Open the project folder:

```bash
cd blog-preview-card
```

3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for a better development experience.
